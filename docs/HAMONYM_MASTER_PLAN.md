# HAMONYM — MASTER PLAN
גרסה 1.0 | 26.11.2026 | יעד השקה: ינואר 2027

## החלטת מוצר מחייבת
ה-Builder נשאר כפי שהוא. אין שכתוב, רפקטורינג רוחבי או שינוי UI שלו. ממשק ניהול קמפיין חי יתוכנן מחדש. שומרים מנועי תרומות, Cardcom, שגרירים, רישום, גבייה, הרשאות והיסטוריה. מתקנים חיבורי נתונים באופן ממוקד לפי צורך מוכח. אין להמיר את המחקר לפרויקט אינטגרציה בלתי מוגבל.

## שערי עבודה
1. כעת: אישור מפת ניווט ואבטיפוס ניהול קמפיין; אין מימוש רחב לפני אישור.
2. לאחר אישור: לכל מסך מגדירים נתונים, מקור אמת, שירות קיים ופעולה; מתקנים רק פערי חיבור נחוצים. מתחילים בפרוסה אנכית אחת (למשל תשורות), לא בכל המערכת. אין להציג רכיב מוסתר אוטומטית.
3. משלימים ניהול קמפיין ואז שגרירים, תורמים/Checkout/קבלות, מנהל עמותה, Super Admin ושותפים; סקירה רוחבית ופורטל.
4. מוכנות להשקה ובדיקות קבלה. אין הבטחת מועד על סמך הרשימה בלבד.

סטטוסים: פתוח | בפיתוח | ממתין לאישור | הושלם. מחקר או קומפילציה אינם אישור. כל משימה נסגרת רק לאחר אישור המשתמש. P0 = חסם/סיכון קריטי, P1 = נדרש לפני השקה, P2 = שיפור לתעדף, D = נדחה. העדיפויות הן הצעת תכנון, לא אישור לביצוע.
