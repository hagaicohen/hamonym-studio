## Campaign boot and refresh

B selects campaign columns plus entity display name/logo/analytics only for published, active-entity, non-hidden, non-deleted campaigns. Registration options are attached separately. For an authenticated owner, F can fall back to owner-scoped `/api/campaigns/slug/:slug` for private viewing; this is not anonymous publication.

## Integration-critical observations

1. Use a separate read-only live-data projection; never write donors, contribution totals, participant records or ambassador ledgers back from `campaignState.current`.
2. F polling currently adds `item.amount` and donation-row count to the displayed snapshot. B live feed returns charged currency/amount, while B campaign total is ILS. Mixed-currency increments can therefore produce an incorrect **client display**. The limit-10/window-watermark design can also miss UI increments during bursts. Prefer refreshing authoritative campaign totals; don't copy this arithmetic into Studio.
   [F/src/app/modules/campaigns/pages/campaign-public-page/campaign-public-page.component.ts:339](C:/DEV/HamonymStudio/hamonym-app/src/app/modules/campaigns/pages/campaign-public-page/campaign-public-page.component.ts#L339); [B/src/modules/donations/donations.service.js:933](C:/DEV/HamonymStudio/hamonym-backend/src/modules/donations/donations.service.js#L933).
3. Feed visibility guards are not identical: campaign and live GET require published/active; donor and reward-count queries check hidden/deleted flags but omit some of those status conditions. A newly public Studio renderer must not assume every feed enforces the campaign page's entire guard.
4. Dashboard cache invalidation occurs after campaign saves and successful payments; the public SQL feeds above are direct queries. Do not describe dashboard caching as a cache for all public modules.
5. Render published Studio document + latest business data through the same Angular presentation components in editor preview/public page. Demo data and previews must not start payments, registrations or comment/ambassador writes.
